Risk Register
Structured Project Risk Identification

KDMine's risk register process follows ISO 31000 and AACE RP 44R-08. Risks are identified through structured workshops with the project team, categorised by type (technical, commercial, geopolitical, environmental), and scored on a 5×5 probability-impact matrix.

Each risk is assigned a risk owner, mitigation action, residual risk score, and contingency allocation. The register is a living document updated at each project milestone.

Monte Carlo Simulation
Probabilistic Cost & NPV Analysis

Monte Carlo simulation replaces single-point cost estimates with probability distributions for each uncertain input variable. By running 10,000+ iterations, we generate a full probability distribution of CAPEX, OPEX, and NPV outcomes — giving decision-makers a P10/P50/P90 view of project economics rather than a single deterministic number.

KDMine's Monte Carlo models are built in Excel with @RISK or Crystal Ball add-ins, or in Python for large-scale simulations. All input distributions are calibrated against project-specific data and industry benchmarks.

1
Define Input Variables
Identify all uncertain cost and revenue inputs. Assign probability distributions (triangular, normal, lognormal) based on data quality.
2
Set Correlations
Define correlation coefficients between related variables (e.g. diesel price and OPEX, gold price and revenue).
3
Run 10,000 Iterations
Latin Hypercube sampling ensures efficient coverage of the full distribution space in 10,000 model runs.
4
Analyse Output Distribution
Generate P10/P50/P90 values, probability of positive NPV, and contribution-to-variance analysis.
5
Determine Contingency
Set contingency at P70–P80 of CAPEX distribution per AACE RP 44R-08 to achieve target confidence level.

Contingency Determination
AACE RP 44R-08 Method

AACE International Recommended Practice 44R-08 provides the industry standard framework for risk-based contingency determination. Contingency is not a flat percentage — it is calculated from the probability distribution of cost outcomes, typically set at P70–P80 to provide a 70–80% confidence level that the project will be completed within the approved budget.

KDMine applies RP 44R-08 to all Class 2 and Class 3 estimates. For Class 4 and 5 estimates, we use the Expected Value method with risk-adjusted unit costs.
