Project Scheduling
From Milestone to Resource-Loaded CPM

KDMine develops project schedules at four levels of detail, from the board-level milestone summary (Level 1) to the fully resource-loaded, logic-linked CPM network used by the construction team (Level 4). All schedules are developed in Primavera P6 or MS Project and are integrated with the project cost estimate.

The critical path is identified and actively managed throughout construction. Float analysis, schedule risk analysis (SRA), and what-if scenarios are used to protect the project completion date.

Earned Value Management
EVM Cost & Schedule Control

Earned Value Management (EVM) integrates scope, schedule, and cost into a single performance measurement system. KDMine implements full EVM systems per AACE TCM and PMBoK standards, providing real-time CPI, SPI and accurate EAC forecasts.

The EVM system is built on a WBS aligned to the project estimate, enabling direct comparison of actual costs against the baseline at each WBS level.
